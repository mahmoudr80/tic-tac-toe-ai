
# Gomoku AI Int

An Intelligent Gomoku Player using the Minimax Algorithm, Alpha-Beta Pruning, and Heuristic Functions.




## Features

- Minimax Algorithm
- Alpha-Beta Pruning
- Heuristic Function
- User Interface
- Adaptive Difficulty Levels
- User-Selected Board Size
