# Tic-Tac-Toe AI — 5×5

A team-developed Tic-Tac-Toe game that expands the classic experience to a 5×5 board, combining game logic, algorithms, data structures, and AI-related decision-making.

**Project Date:** December 2025  
**Team Size:** 5 members  
**Role:** Team Leader

---

## Overview

Developed from scratch in collaboration with a team of five, this project explores the design and implementation of a 5×5 Tic-Tac-Toe game. The work focused on game mechanics, board-state management, algorithmic problem-solving, and AI-related gameplay logic.

As the team leader, I helped guide the project and coordinate the team's development efforts toward completing the game.
